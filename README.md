# Poligonais ANM - Paracatu e Kinross Brasil

Base consultada em 16/10/2026, fonte oficial ANM/SIGMINE.

- **237 poligonais** do titular **KINROSS BRASIL MINERACAO S/A**, em MG (122), GO (107), PA (7) e MT (1).
- Camada anterior: 117 poligonais / 115 processos distintos. A consulta nacional acrescenta 120 processos; nenhum dos processos anteriores ficou ausente.
- `Kinross_Brasil_ANM.kml` e `.kmz`: camada nacional completa da Kinross.
- `Kinross_Paracatu_60km_AppSheet.kml`: mesmo conteudo nacional, com o nome anterior preservado para os links existentes do AppSheet.
- `ANM_Paracatu_MG_60km_completo.kmz`: mantem os demais titulares da regiao de Paracatu e agora inclui toda a Kinross Brasil (1800 registros no total). Nome anterior preservado por compatibilidade.
- `ANM_Paracatu_e_Kinross_Brasil_completo.kmz`: copia do completo com nome explicito para o novo escopo.
- `ANM_outros_Paracatu_60km_parte_1.kml` e `_parte_2.kml`: demais titulares do recorte anterior, preservados.

A camada Kinross continua dourada. As geometrias e atributos dos processos foram preservados. A selecao nacional usa o titular cadastrado na ANM; nao inclui subsidiarias com outras razoes sociais e nao representa todos os processos historicos encerrados. Consulta atual de processos ativos, incluindo disponibilidade conforme a ANM. Os arquivos sao uma fotografia da consulta, sem atualizacao automatica.

A camada Kinross tem menos de 1000 elementos e menos de 3 MB. O KMZ completo excede 1000 elementos e e destinado ao Google Earth; no AppSheet, usar os KMLs separados.
